- 低延迟套餐：主打游戏加速和4K/8K视频播放，节点优化得特别好，如果你对延迟敏感，选这个准没错。

别贪贵，先评估自己的需求。如果你只是偶尔用用，经济套餐完全够了；如果你是重度用户，直接上低延迟，体验会好很多。

第四步：填写订单，确认信息
登录用户中心，再次确认你要购买的套餐，然后填写一些基本联系信息。这里要特别留意邮箱地址，因为后续的配置文件和账单都会发到这个邮箱。填错了可收不到重要资料。

第五步：支付，支持多种方式

第六步：等待分配，查收邮件
正常情况下，几分钟内系统就会自动分配服务器并生成配置文件。你会收到一封标题类似“Your V2Ray Configuration is Ready”的邮件，里面包含一个config.json文件下载链接，以及你的专属UUID、服务器地址和端口号。这封邮件非常重要，建议立刻下载并备份到本地。

第三章：客户端安装与配置——别怕，跟着做就行

有了配置文件，接下来就是安装客户端了。这一步对于新手来说可能有点懵，但只要你按我的步骤来，绝对零失误。

下载客户端：选对版本
V2Ray官方客户端支持Windows、macOS、Linux、iOS和Android。官网下载页面会提供对应的安装包。Windows用户建议下载exe安装版，macOS用户选dmg文件。手机用户直接在应用商店搜索“V2Ray”或“v2rayNG”（安卓）、“Shadowrocket”（iOS，付费）即可。

安装注意事项
安装过程中，Windows系统可能会弹出防火墙提示，一定要勾选“允许访问”，否则客户端无法正常连接网络。另外，如果你用的是macOS，首次打开可能需要右键点击图标选择“打开”，绕过系统安全限制。

配置步骤详解
1. 导入配置文件：打开客户端，找到“配置”或“导入”按钮，选择你从邮件中下载的config.json文件。客户端会自动解析里面的服务器地址、端口、UUID等信息。
2. 手动核对关键参数：如果你不想导入文件，也可以手动填写。打开配置文件，你会看到类似这样的内容：
json { "address": "server.example.com", "port": 443, "id": "你的UUID", "protocol": "vmess" }
确保客户端里的服务器地址、端口和UUID与文件完全一致。
3. 选择传输协议：根据你的网络环境，在客户端里选择TCP、WebSocket或gRPC。默认情况下TCP最稳定，但如果你的网络封锁比较严格，可以尝试WebSocket+CDN的方式。
4. 启动连接：配置无误后，点击“连接”或“启动”按钮。客户端会显示连接状态，如果成功，你会看到“已连接”或类似提示。

测试连接，别急着高兴
连接成功后，打开浏览器访问一个国内无法访问的网站（比如Google或YouTube），如果能正常加载，说明配置完全正确。如果打不开，别慌，往下看常见问题部分。

第四章：进阶技巧——让V2Ray更流畅、更安全

配置好只是第一步，想要用得舒心，还有几个小技巧值得掌握。

技巧一：多节点切换，应对突发状况
链接空间的用户中心通常会提供多个节点（比如香港、日本、新加坡、美国等）。当你觉得当前节点速度变慢或连接不稳定时，可以回到用户中心，复制其他节点的配置信息，在客户端里新建一个配置并切换过去。这招在高峰期尤其管用。

技巧二：开启系统代理，全局接管
如果你希望所有网络流量都通过V2Ray（而不仅仅是浏览器），可以在客户端里开启“系统代理”或“全局模式”。这样，包括游戏、邮件客户端、命令行工具在内的所有应用都会走加密通道。不过要注意，全局模式可能会影响国内网站访问速度，建议日常使用“PAC模式”或“规则模式”，让国内流量直连，国外流量走代理。

技巧三：定期更新，保持最佳性能
链接空间会不定期升级服务器和协议，以对抗新的封锁手段。建议每隔一两个月登录用户中心，查看是否有新版本配置文件或客户端更新。及时更新，能避免因协议过时而导致的连接失败。

技巧四：使用路由规则，精细化管理
如果你是个进阶用户，可以在客户端里自定义路由规则。比如，指定某些IP段或域名走代理，其他流量直连。这样既能保证速度，又能保护隐私。链接空间的配置文件里已经预设了一些基础规则，你可以在此基础上修改。

第五章：常见问题解答——你遇到的坑，我都踩过

问：购买后多久能收到配置？
答：正常情况下，支付完成后1-3分钟内系统会自动发送邮件。如果超过10分钟还没收到，检查一下垃圾邮件箱，或者联系客服提供订单号查询。

问：连接成功但无法访问外网，怎么办？
答：先检查系统时间是否准确——V2Ray的加密机制对时间偏差很敏感，误差超过60秒就会导致握手失败。其次，尝试切换节点或协议。如果还不行，关闭本地防火墙或杀毒软件再试。

问：手机端能用同一个配置吗？
答：完全可以。只要在手机客户端里导入相同的config.json文件，或者手动输入服务器地址、端口和UUID即可。不过要注意，手机客户端可能需要额外开启“VPN”权限，系统会提示你允许。

问：忘记UUID了，怎么找回？
答：登录链接空间用户中心，在“我的服务”或“订单详情”里可以查看完整配置信息，包括UUID。如果找不到，直接联系在线客服，提供注册邮箱即可。

问：一个账号能同时几台设备使用？
答：取决于你的套餐。经济套餐一般支持2-3台设备同时在线，高级套餐支持5台以上。如果你需要更多设备，可以在用户中心购买额外的设备授权。

问：为什么速度有时候快有时候慢？
答：这跟你的物理位置、本地网络环境以及目标网站的服务器位置都有关系。建议选择离你最近的节点（比如大陆用户选香港或日本），同时避开晚高峰（晚上8-11点）进行大流量操作。

FAQ

何为 fake-ip 模式，它的优缺点是什么？
fake-ip 是通过伪造 DNS 返回的 IP 地址让客户端透明代理流量，优点是兼容性好、无需修改应用代理设置；缺点是可能导致某些证书校验或 SNI 伪装失效，需要配合 DNS 与证书策略谨慎使用。
Nekoray 与 Nekobox 有什么不同？
Nekoray 是一款基于 Qt 的跨平台代理前端，而 Nekobox 更偏向移动端简化使用。两者均支持 V2Ray/VLESS/Trojan 协议，但 Nekobox 提供了更轻量的界面和更快的连接启动速度。

Potatso Lite 手动节点切换有哪些优点？

Surfboard 的配置文件可以手动编辑吗？
